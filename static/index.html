Input conventions & category codes

X7 is a fraction (0.25 = 25% of floor area). X6 uses source orientation codes 2–5. X8 uses 0 = no glazing, 1 = uniform, 2–5 = north/east/south/west emphasis. Physical input scales must match the source benchmark; no automatic unit conversion is performed.
